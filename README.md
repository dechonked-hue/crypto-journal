# Crypto Journal

A developer-first crypto journal, built with Astro and the NeonMint template.

- Site: https://crypto-journal.dechonked.workers.dev/
- Posts live in `src/pages/blog/posts/` as Markdown.
- Categories in this journal: Execution Logs & Backtests, Automation & Infrastructure, Self-Custody & Key Hygiene, Macro & Asset Accumulation.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
